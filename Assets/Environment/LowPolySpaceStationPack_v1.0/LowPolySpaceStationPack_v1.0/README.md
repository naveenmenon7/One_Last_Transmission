# Low Poly Space Station Pack (Free)
by reodesuxz

28 low poly sci-fi space station interior assets: corridors, airlocks, consoles, bunks, reactor and more.

## Contents
- FBX/  - one .fbx per model (Unity, Unreal, Godot, Blender)
- GLB/  - one .glb per model (Godot, three.js, Babylon.js, web)
- OBJ/  - one .obj + .mtl per model
- SpaceStation_AllAssets.blend - every model in one Blender file (Blender 4.3+)

## Specs
- Total: 3148 triangles for all 28 models (24-252 tris each)
- Flat-shaded, simple shared materials (no textures needed)
- Real-world scale in metres, pivot at the base centre
